# 삼각비 개념 학습 (Trigonometry Concept)

중학교 3학년 「삼각비」 단원 **개념 학습용** 웹 페이지입니다.
도입 활동(복습·에스컬레이터·탈레스)을 뺀 6개 활동으로 구성되어 있습니다.

설치 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있고, **인터넷 연결 없이도 동작**합니다.

## 1. 구성

| 활동 | 내용 |
|---|---|
| 1. 각이 같으면 변의 비도 같을까요? | **(탐구)** 각 A를 고정하고 삼각형 크기만 바꿔 보며, 두 변의 길이의 비가 일정함을 표로 확인. 아직 삼각비라는 말을 쓰지 않습니다 |
| 2. 삼각비란 무엇인가요? | 1번에서 찾은 세 가지 비에 sin·cos·tan이라는 이름을 붙입니다 |
| 3. 특수각의 삼각비 | 0°·30°·45°·60°·90° 표 — 칸을 눌러 값 확인, 전체 보기 / 전체 숨기기 |
| 4. 사분원에서 보는 삼각비 | 반지름 1인 사분원에서 세 삼각비를 선분으로 표현. 슬라이더·특수각 버튼으로 조작 |
| 5. 삼각비의 표와 계산기 | 0°~90° 1° 간격 표 + 각도를 입력하면 해당 줄을 찾아 주는 도구 |
| 6. 실생활 활용 | 나무 높이·경사로·사다리 문제 3개 (풀이 접기/펼치기) |

## 2. 수업에서 쓰는 방법

- **한 번에 한 활동만** — 상단 메뉴(1~6)를 누르면 그 활동만 화면에 나타납니다.
- 각 활동 아래의 **← / → 버튼**으로도 이동할 수 있고, 가운데에 `3 / 6`처럼 진행 위치가 표시됩니다.
- 주소 뒤에 `#trends`처럼 붙이면 **그 활동으로 바로 열립니다.** 브라우저 뒤로 가기도 동작합니다.

  | 활동 | 주소 뒤에 붙일 것 |
  |---|---|
  | 1. 각과 변의 비 | `#similar` |
  | 2. 삼각비란 | `#definition` |
  | 3. 특수각 | `#values` |
  | 4. 사분원 | `#trends` |
  | 5. 삼각비의 표 | `#tables` |
  | 6. 실생활 활용 | `#apply` |

- **색 약속** — sin은 파랑, cos는 주황, tan은 빨강, 빗변은 회색. 모든 그림과 표가 같은 색을 씁니다.
- **가리고 묻기** — 표의 칸과 값 패널은 처음에 `?`로 가려져 있습니다. 학생에게 먼저 묻고 눌러서 확인하세요.
- **큰 글씨 버튼** — 오른쪽 위 버튼을 누르면 전자칠판·프로젝터용으로 글씨와 그림이 커집니다.
- **인쇄** — 6개 활동이 모두, 가려둔 답과 풀이가 펼쳐진 채로 출력됩니다. 학습지로 쓸 수 있습니다.
- **키보드** — 표의 칸과 값 패널은 Tab으로 이동해 Enter/Space로 열 수 있습니다.

### 1번 섹션(탐구) 수업 흐름 제안

1. 각 A를 30°로 맞춘 뒤 **크기 슬라이더만** 좌우로 움직입니다.
2. "높이·밑변·빗변 숫자는 어떻게 되나요?" → 전부 달라집니다.
3. "그럼 오른쪽 파란 칸(비)은요?" → **세 줄이 모두 같습니다.**
4. 각 A를 45°, 60°로 바꾸면 비의 값이 달라지는 것을 확인 → **비는 크기가 아니라 각으로 정해진다.**
5. 흐리게 그려진 두 삼각형(c=5, c=10)으로 세 삼각형이 닮음임을 눈으로 확인합니다.
6. "이렇게 각으로만 정해지는 값이라면 이름을 붙여 두면 편하겠지요?" → **2번 섹션으로.**

> 1 → 2번의 순서는 의도적입니다. 용어(sin·cos·tan)를 먼저 주지 않고 **비가 일정하다는 사실을 먼저 발견**하게 한 뒤 이름을 붙입니다. 그래서 1번 표의 열 이름도 `a ÷ c`처럼 비 자체로만 적혀 있습니다.

## 3. 지도상 유의점

- `tan 90°`는 **무한대(∞)가 아니라 "정할 수 없다"** 로 표기했습니다. 90°에서는 밑변의 길이가 0이 되어 나눗셈이 성립하지 않기 때문입니다.
- 4번 그림에서 각이 커지면 **세로 눈금이 1.5 → 2 → 3으로 자동으로 넓어집니다.** tan이 커지는 모습을 보여주기 위한 것이며, 화면 아래에 안내 문구가 나옵니다.
- 71° 부근을 넘으면 tan 선분에 화살표가 붙고 "화면을 넘어설 만큼 커졌습니다"라고 표시됩니다.
- 삼각형 표기는 교과서 관례를 따랐습니다. ∠C = 90°, 대변은 각각 a(높이), b(밑변), c(빗변).

## 4. 기술

- HTML5 / Vanilla CSS / Vanilla JS — **외부 라이브러리·CDN을 전혀 쓰지 않습니다.**
- 본문 글꼴은 시스템에 기본 설치된 한글 글꼴(맑은 고딕, Apple SD Gothic Neo 등)을 사용합니다.
- 숫자·수식에는 `fonts/` 폴더의 D2Coding을 로컬로 불러옵니다.
- 사분원 그림은 JavaScript로 SVG를 그립니다.
